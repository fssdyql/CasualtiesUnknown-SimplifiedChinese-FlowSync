# CasualtiesUnknown-SimplifiedChinese-FlowSync

**基于官方翻译库深度优化的《未知伤亡》沉浸式高精度简体中文汉化包**

当前版本：v0.1.7 | 适用游戏版本：v7.0.1-steam(DEMO)

---

### 项目简介

在《未知伤亡》(Casualties Unknown) 极度硬核的生存环境中，玩家每一次用药、每一次进食都需要精确的计算。传统的汉化补丁往往偏向于“维基百科”式的全包揽，在物品描述中塞入大量冗长的背景设定和合成配方，导致UI界面拥挤不堪。

**FlowSync (FS版)** 的诞生正是为了解决这一痛点。

本项目基于官方翻译库(zh-CN)进行深度重构，剔除了所有冗余的废话。我们致力于将游戏内的物品描述改造为极简、直观的**“战术数据面板”**，让你在争分夺秒的绝境中，一眼锁定关键数值。

---

### 核心设计理念

*   **现代化UI排版**
    摒弃了容易导致界面拉伸和视觉疲劳的全角制表符（如 `┃`）。采用标准空格缩进与严格的色彩管理方案：正面增益统一为绿色，负面消耗与副作用统一为红色。信息层级分明，视觉体验清爽。
*   **高精度底层数据**
    直接对齐游戏底层逻辑。对于复杂的医疗药品、液体混合物以及武器伤害，提供精确到毫升(ml)与小数点的硬核数据（如：不同给药途径的具体数值差异、过量阈值警告）。
*   **极致的去冗余化**
    “游戏系统已经提供的信息，绝不占用宝贵的屏幕空间”。由于游戏内已具备蓝图和制作标签系统，本汉化包移除了物品描述中占地方的合成公式，将所有版面留给决定生死的生存数据。

---

### 汉化覆盖范围

为保持补丁的纯粹性与轻量化，FlowSync 版本专注于对游戏体验影响最深的模块。

**目前已深度重构的内容：**
- **全部实体物品**（消耗品、武器、防具、工具、容器及各类材料）
- **全部液体与化学品**（详细的口服/静脉注射双重判定数据）

*(注：系统UI、剧情对话等基础内容依然沿用官方库标准文本。)*

### 安装指南（面向新玩家）

本汉化包的使用极其简单，不会修改游戏核心文件，安全无冲突。

**步骤 1：下载汉化文件**
在本项目页面下载最新的 `.json` 汉化文件。

**步骤 2：找到游戏目录**
打开 Steam，在库中右键点击 `未知伤亡 试用版` -> 选择 `管理` -> 选择 `浏览本地文件`。

**步骤 3：放入汉化文件**
在打开的游戏根目录中，找到 `CasualtiesUnknown_Data` 下的 `Lang` 文件夹。将刚才下载的 `.json` 文件直接复制到该文件夹内。

**步骤 4：在游戏中启用**
启动游戏，进入设置 (Settings) -> 语言 (Language) 选项，在下拉菜单中找到并选择带有 **FS简中** 字样的语言包，应用即可生效。

### 常见问题解答 (Q&A)

**Q：为什么我在物品描述里看不到怎么合成它了？**
A：游戏内置的制作面板和蓝图系统已经清楚地展示了合成需求。为了保持界面的极致整洁，FS版移除了这些重复信息，专注于展示物品的实际使用效果和隐藏机制。

**Q：这个汉化包会和其他Mod/汉化冲突吗？**
A：完全不会。这只是一个标准的本地化语言文件，只要在游戏设置中选中它即可，随时可以切换回其他语言版本。
